# Obsidian 노트를 블로그 글로 옮겨 적을 때

노트 파일을 그대로 올리는 것이 아니라 **내용을 새 글로 옮겨 적는** 경우를 기준으로 합니다.
Obsidian 보관함과 블로그는 구조가 다르므로 아래 차이만 주의하면 됩니다.

> 표의 "결과"는 실제로 빌드해서 확인한 내용입니다.

## 1. 바꿔 써야 하는 문법

Obsidian 문법은 사이트에서 **글자 그대로** 출력됩니다.

| Obsidian | 사이트에서의 결과 | 블로그용으로 바꾸기 |
| --- | --- | --- |
| `[[위키링크]]`, `[[글\|별칭]]` | 대괄호 글자 그대로 | 일반 링크 `[글](../다른-글/)` |
| `![[pic.png]]` (임베드) | `![[pic.png]]` 글자 그대로 | `![](pic.png)` |
| `> [!note] 제목` (콜아웃) | 일반 인용문에 `[!note]` 글자가 노출 | `:::note[제목]` … `:::` |
| `[글](다른-글.md)` (파일 링크) | 링크가 `다른-글.md` 로 남아 **404** | 아래 "글 사이 링크" 참고 |

콜아웃 대신 쓰는 admonition 종류는 `note`, `tip`, `important`, `warning`, `caution` 입니다.

```md
:::tip[제목]
본문
:::
```

## 2. 글 사이 링크

이 사이트는 두 곳에 배포됩니다.

- Cloudflare Pages: `https://…pages.dev/posts/내-글/`
- GitHub Pages: `https://n-isoge.github.io/my_small_recipe_book/posts/내-글/` (하위 경로)

글 본문의 링크에는 `/my_small_recipe_book` 이 자동으로 붙지 않으므로 **상대 경로**로 씁니다.

| 쓰는 방식 | Cloudflare | GitHub Pages |
| --- | --- | --- |
| `[글](../다른-글/)` | 정상 | 정상 |
| `[글](/posts/다른-글/)` (루트 기준) | 정상 | **사이트 밖을 가리켜 깨짐** |
| `[글](다른-글.md)` (파일 링크) | **404** | **404** |

현재 글이 `/posts/내-글/` 이면 `../다른-글/` 은 `/posts/다른-글/` 이 됩니다.
글을 폴더 구조로 만든 경우(`content/posts/내-글/index.md`)에도 같은 규칙입니다.
하위 폴더에 둔 글(`content/posts/시리즈/글1.md`)은 주소가 `/posts/시리즈/글1/` 이므로 `../` 개수가 달라집니다 (`../글2/` 는 `/posts/시리즈/글2/`).

Obsidian 안에서 이 링크를 눌러도 파일로 이동하지는 않습니다. (Obsidian 에서도 눌리게 하려면 `.md` 링크를 주소로 바꾸는
플러그인을 추가해야 하는데, 직접 작성하는 코드가 늘어서 현재는 쓰지 않습니다.)

## 3. 이미지

글과 **같은 폴더**에 두고 상대 경로로 씁니다. 아래 형식은 모두 동작하고 자동으로 최적화(webp)됩니다.

```md
![설명](pic.png)
![설명](./pic.png)
![설명](pic%20two.png)   <!-- 공백은 %20 -->
```

## 4. 프런트매터

### 글 (`content/posts/`)

```yaml
---
title: 글 제목 (60자 이내)
description: 한두 문장 요약
publishDate: 2026-10-09
tags:
  - obsidian
draft: true
---
```

| 속성 | 필수 | 설명 |
| --- | --- | --- |
| `title` | O | 60자 이내 |
| `description` | O | 길이 제한은 없지만 검색/공유용으로 50~160자 권장 |
| `publishDate` | O | `2026-10-09` 처럼 날짜만 또는 날짜+시간. 따옴표 유무와 관계없이 동작 |
| `updatedDate` | | 있으면 이 날짜로 정렬 |
| `tags` | | 소문자로 바뀌고 중복은 제거됨. 공백이 있으면 주소에도 공백이 들어가므로 하이픈 권장 |
| `draft` | | `true` 면 **운영 빌드에서 제외**됨 (개발 서버에서는 보임) |
| `pinned` | | 목록 상단 고정 |
| `coverImage` | | `src: ./cover.png` 와 `alt: 설명` 둘 다 필요 |

Obsidian 이 붙이는 `aliases`, `created`, `cssclasses` 같은 **다른 속성은 에러 없이 무시**됩니다.

### 짧은 노트 (`content/notes/`) — ⚠️ 날짜 형식 주의

```yaml
---
title: 짧은 노트 제목
publishDate: "2026-10-09T10:00:00+09:00"
---
```

노트의 `publishDate` 는 **따옴표로 감싼 ISO 형식에 시간대(`Z` 또는 `+09:00`)가 있어야** 합니다.

| 값 | 결과 |
| --- | --- |
| `"2026-10-09T10:00:00+09:00"`, `"2026-10-09T01:00:00Z"` | 됨 |
| `2026-10-09T10:00:00+09:00` (따옴표 없음) | 빌드 실패 |
| `"2026-10-09T10:00"` (시간대 없음), `"2026-10-09"` (날짜만) | 빌드 실패 |

Obsidian 의 날짜 속성은 따옴표와 시간대가 없는 값을 만들므로 노트에는 쓰지 말고 직접 입력하세요.

## 5. 옮겨 적은 뒤 확인

남은 Obsidian 문법 찾기 (결과가 없어야 함):

```sh
grep -rnIE '\[\[|!\[\[|\[!(note|tip|warning|info)|\]\([^)]*\.mdx?\)' content/posts
```

- `pnpm dev` 로 화면 확인 (`draft: true` 글도 보임)
- 공개할 때 `draft: false` 로 바꾸고 `dev` 에 푸시해 테스트 배포를 확인한 뒤 `main` 으로 올립니다.
